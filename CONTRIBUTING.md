# Contributing

Issues, pull requests, and translation corrections are welcome.

For bugs, include your macOS version, the affected application, steps to reproduce, expected behavior, and actual behavior. Remove private information from screenshots and logs before sharing.

Keep changes focused on Dock previews and window interaction. Build with the README instructions, run the relevant built-in checks, and describe manual testing. Experimental behavior must have an actual implementation and clearly documented limits.

By contributing, you agree that your contribution is distributed under this project's MIT License.
